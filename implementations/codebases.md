# Codebases

This page tracks repositories for methods and systems.

## Fields to record

- Official repo URL.
- Code status: `released`, `partial`, `unreleased`, `not_found`, or `unknown`.
- Training support versus inference/evaluation only.
- Framework dependencies.
- License, if known.
- Reproducibility level.

## Current caution

Do not mark a method reproducible because model weights exist. OPD reproducibility requires enough code or recipe detail to reproduce the on-policy training loop.
