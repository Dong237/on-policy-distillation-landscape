# Datasets

Dataset tracking should distinguish offline teacher data from online rollout data.

## Dataset roles

| Role | Meaning |
|---|---|
| Cold-start SFT | Fixed data used before online training. |
| On-policy rollout prompts | Prompts used for student-generated trajectories. |
| Teacher supervision data | Teacher labels/logits/feedback computed on student rollouts. |
| RLVR reward data | Problems with verifiable answers or environment rewards. |
| Evaluation data | Benchmarks only; not training data. |

## VLM caution

Multimodal SFT data generated by GPT-4V, Gemini, or another VLM is not OPD unless the student generates the states that are then supervised.
