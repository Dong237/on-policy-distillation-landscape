# Black-Box OPD Reading Path

## Audience

Readers interested in closed teacher APIs, response-only feedback, discriminators, and adversarial alignment.

## Goals

- Distinguish black-box OPD from synthetic data generation.
- Understand why response-level OPD often stays partial, borderline, or adjacent.

## Path

1. Read [Teacher access](../taxonomies/by-teacher-access.md).
2. Read [Black-box and API OPD](../papers/black-box-and-api-opd.md).
3. Read PRISM as a multimodal adjacent example after the latest verifier pass: the response-level discriminator reward is not a distillation loss.
4. Compare against offline synthetic-data methods in [Adjacent work](../taxonomies/adjacent-work.md).
