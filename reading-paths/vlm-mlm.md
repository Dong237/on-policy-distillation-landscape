# VLM / MLLM OPD Reading Path

## Audience

Readers focused on visual reasoning, multimodal post-training, video grounding, documents, GUI, or VLA systems.

## Goals

- Separate strict VLM OPD from VLM RLVR and offline MLLM KD.
- Understand why current VLM OPD evidence is sparse.
- Track the seed strict, borderline, and adjacent boundary methods.

## Path

1. Read [LLM vs VLM OPD](../notes/llm-vs-vlm-opd.md).
2. Read [Multimodal frontiers](../papers/multimodal-frontiers.md).
3. Inspect `tables/vlm_opd_papers.md`.
4. Inspect `tables/adjacent_work.md` for VLM-R1-style RLVR methods.
5. Inspect `tables/industrial_reports.md` before making claims about Qwen, InternVL, Gemma, Gemini, MiniCPM-V, or LLaVA systems.

## Start with

- VOLD
- Video-OPD
- Uni-OPD
- VLA-OPD as embodied/VLA extension
- GUI-SD and LiteGUI for GUI grounding or GUI-agent stage-scoped OPD
- KEPO, D-OPSD, and Flow-OPD as borderline frontier cases
- PRISM as an adjacent black-box response-alignment boundary
