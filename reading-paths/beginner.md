# Beginner Reading Path

## Audience

Readers new to OPD who need to distinguish it from SFT, offline KD, DPO, RLHF, and RLVR.

## Goals

- Understand the strict OPD definition.
- Learn why rollout source matters.
- Read the foundational OPD papers before VLM extensions.

## Path

1. Read [strict OPD definition](../taxonomies/strict-opd-definition.md).
2. Read [OPD vs SFT](../notes/opd-vs-sft.md), [OPD vs offline KD](../notes/opd-vs-offline-kd.md), and [OPD vs RLVR](../notes/opd-vs-rlvr.md).
3. Read GKD and MiniLLM in [Foundations and theory](../papers/foundations-and-theory.md).
4. Skim [Multimodal frontiers](../papers/multimodal-frontiers.md) to see why multimodal OPD is still emerging.
