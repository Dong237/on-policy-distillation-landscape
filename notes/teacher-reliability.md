# Teacher Reliability

Teacher feedback is useful only when the teacher is reliable on states visited by the student.

## Track

- Does the paper filter teacher feedback?
- Does it estimate teacher uncertainty?
- Does it use outcome rewards to calibrate teacher guidance?
- Does it separate perception feedback from reasoning feedback?
- Does it handle teacher-student distribution mismatch?

## VLM note

A text-only teacher can improve reasoning while still failing to identify visual perception mistakes. VLM OPD should record teacher modality and likely failure mode.
