# LLM vs VLM OPD

LLM OPD usually supervises text tokens generated by the student. VLM/MLLM OPD adds visual context, multimodal grounding, and perception failures.

## Key differences

| Issue | LLM OPD | VLM / MLLM OPD |
|---|---|---|
| State | Text prefix and generated tokens | Image/video/document/GUI context plus text trajectory |
| Teacher reliability | Mostly language reasoning | May fail on perception or grounding |
| Feedback | Token KL, sequence feedback, reward | Token KL, visual grounding feedback, perception/reasoning split |
| Failure mode | Exposure bias, long-CoT drift | Perception error, text-only teacher mismatch, visual shortcutting |
| Benchmarks | Math, code, instruction following | MathVista, MMMU-Pro, OCRBench, ChartQA, DocVQA, video, GUI |

## Current conclusion

VLM/MLLM strict OPD is still thin. The current strict seed set is VOLD, Video-OPD, Uni-OPD, VLA-OPD, GUI-SD, and the LiteGUI guided stage, with X-OPD as a cross-modal speech extension. PRISM is now adjacent after the latest verification because its response-level MoE discriminator signal is consumed as scalar policy-gradient reward rather than a token/logit distillation loss. Most VLM GRPO/RLVR work is adjacent.
