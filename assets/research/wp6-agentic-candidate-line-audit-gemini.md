## Memo

Of the 11 candidates in this queue, **3** pass as `strict_opd` against verified arXiv abstracts (TCOD, LiteGUI, Skill-SD), **1** as `strict_opd_limited` (GUI-SD; single-step GUI grounding only), **2** as `borderline_strict` (OEC — DAgger-style hard expert completions; OpenClaw-RL HG-OPD — hindsight-guided self-teacher that feeds "token-level directional advantage" rather than a pure KL), **2** as `partial_opd` (RLSD — teacher distribution determines gradient magnitude only, with reward supplying direction; DGPO — teacher KL consumed by PPO advantage estimator), **1** as `adjacent` (RISE — reward-weighted SFT; paper explicitly disclaims "classic knowledge distillation"), **1** as `not_opd / offline_imitation` (SAD — teacher-forced alignment on pre-collected teacher trajectories), and **1** as `unclear / borderline_strict_industrial` (GLM-5 — the public abstract does not expose cross-stage OPD loss form; label stays conservative).

**Strict agentic OPD (C1+C2+C3 in the primary abstract):**
- **TCOD** (arXiv 2604.24005) — explicitly names "On-policy distillation (OPD) … transferring reasoning ability … to smaller students" and diagnoses "Trajectory-Level KL Instability" as student-trajectory KL that rises during multi-turn training (so the student is the sampler). The temporal curriculum controls trajectory depth exposed to the student and progressively expands it — the loss form is vanilla OPD-KL, strictness is inherited.
- **LiteGUI** (arXiv 2605.07505) — "first systematic integration of generalized knowledge distillation into the GUI agent domain via Guided On-policy Distillation"; "oracle reference trajectories" act as privileged context on student-generated GUI actions. The Stage-2 multi-solution dual-level GRPO is a separate stage and does not affect the Stage-1 OPD loss.
- **Skill-SD** (arXiv 2604.10674) — "turns the agent's own trajectories into dynamic training-only supervision"; "importance-weighted reverse-KL loss to provide gradient-correct token-level distillation"; "dynamically synchronize the teacher with the improving student". Skills are a privileged-self-teacher conditioning channel; the student samples under plain prompt. Strict on multi-turn agent states (AppWorld, Sokoban).

**Strict-limited:**
- **GUI-SD** (arXiv 2605.00642) — single-step privileged-visual self-teacher supplies a weighted reverse-KL on student coordinate tokens. Strict for GUI **grounding**, not multi-step GUI control (co-audit row inherited from [wp6-agentic-opd-chatgpt.md](file:///Users/bytedance/Desktop/Work/on-policy-distillation-landscape/assets/research/wp6-agentic-opd-chatgpt.md); flagged for independent re-fetch).

**Borderline strict:**
- **OEC** (arXiv 2512.14895) — "partially on-policy data generated by starting rollouts with a student model and then switching to an expert model part way through the trajectory". C1 holds for the student prefix; expert completions supply hard actions at student-visited states. C3 is cross-entropy / rejection-sampling-SFT on expert tokens, not a distillation-style distributional objective — DAgger-style hard labels, so downgrade.
- **OpenClaw-RL HG-OPD** (arXiv 2603.10165) — "Hindsight-Guided On-Policy Distillation … extract textual hints from the next state, construct an enhanced teacher context, and provide token-level directional advantage supervision". C1 holds (student generates each interaction); C2 holds (hindsight-conditioned self-teacher). C3 is described as "directional advantage supervision", i.e., the teacher signal enters the update as a PG advantage term, not a pure token KL — the full system also folds in a PRM scalar reward, so method-level row is borderline.

**Partial OPD:**
- **RLSD / Self-Distilled RLVR** (arXiv 2604.03128) — explicitly "leverage self-distillation to obtain token-level policy differences for determining fine-grained update magnitudes, while continuing to use RLVR to derive reliable update directions from environmental feedback". C1 holds; C2 holds via the privileged self-teacher; C3 is partially satisfied — teacher evidence ratios modulate magnitude, but direction comes from scalar reward. By construction this is a decoupled hybrid, not strict OPD.
- **DGPO** (arXiv 2508.20324) — "cold-start initialization from teacher demonstrations and continuous teacher guidance during policy optimization". The abstract does not expose a token-level KL loss on student trajectories; community accounts ([wp6-agentic-opd-claude.md](file:///Users/bytedance/Desktop/Work/on-policy-distillation-landscape/assets/research/wp6-agentic-opd-claude.md#L73)) indicate the teacher KL is consumed by PPO's advantage estimator rather than as a direct distillation loss. Partial at best; adjacent is defensible.

**Adjacent (not strict OPD):**
- **RISE** (arXiv 2407.18219) — "iterative fine-tuning procedure, which attempts to teach the model how to alter its response after having executed previously unsuccessful attempts … with optionally additional environment feedback". The paper explicitly positions itself as "inspired by principles in online imitation learning and reinforcement learning"; the distillation-variant consumes teacher text via reward-weighted SFT, not KL. C3 fails.

**Not OPD / offline imitation:**
- **SAD / Structured Agent Distillation** (arXiv 2505.13820) — "Unlike standard token-level distillation, our method segments trajectories into [REASON] and [ACT] spans, applying segment-specific losses to align each component with the teacher's behavior". The supervised trajectories are pre-collected teacher ReAct traces; the student is teacher-forced on those spans. C1 fails — this is offline span-aware KD / behavioral cloning, not OPD. Legacy classification as strict is incorrect; correct label is `not_opd / offline_kd`.

**Unclear / industrial:**
- **GLM-5** (arXiv 2602.15763) — the public abstract names "asynchronous RL infrastructure" and "asynchronous agent RL algorithms" but does not expose a cross-stage OPD loss form, teacher specification, or rollout-freshness guarantee. Community references "On-Policy Cross-Stage Distillation" are not line-visible in the v2 abstract. Conservative label is `borderline_strict_industrial` pending independent line audit of §-level material.

**Caveats:**
- Every 2602.x / 2603.x / 2604.x / 2605.x preprint is post-knowledge-cutoff; quotes below are reproduced from arXiv abstracts fetched at audit time. Confidence is annotated per row. No new arXiv IDs are introduced beyond the 11 assigned candidates.
- No name-collision resolution was required — each acronym matches a unique primary source in the queue.
