## Memo

Of the 14 candidates in this queue, **9** pass as `strict_opd` against verified abstract/HTML quotes, **1** is `borderline_strict`, and **4** downgrade to `partial_opd` (or weaker). No new papers are introduced; all acronyms match a single primary source so no name-collision resolution was needed inside this queue.

**Strict OPD (C1 + C2 + C3 all explicit in the primary source):**
vOPD, TIP, AOPD, StableOPD, SOD, SimCT, OPSDL, DP-OPD, Rock Tokens. These sources either restate the canonical OPD definition verbatim ("trains a student on its own rollouts under token-level supervision from a teacher") or give a point-wise/reverse-KL equation with the student as the sampler. For Rock Tokens the contribution is a gradient-freeze weighting on top of a vanilla OPD loop, so C1/C2/C3 inherit directly from the cited OPD objective.

**Borderline strict:** CaOPD — the paper explicitly self-distills "through the same self-distillation pipeline" on student rollouts but replaces the teacher-conditioned confidence target with an empirical rollout-derived target. Strictness is preserved for capability distillation but the recalibration substep re-targets the objective away from the literal teacher distribution, so I downgrade one level.

**Partial / downgraded:**
- **DSKD v2**: explicitly a "general KD framework that supports both off-policy and on-policy KD". The abstract does not commit to a same-rollout teacher evaluation after projection; strict label would require §-level evidence that the projected teacher distribution is evaluated on student-generated text states during the on-policy mode. Downgrade per the C2 cross-tokenizer rule.
- **SelecTKD**: "works with on- and off-policy data"; the on-policy track is propose-and-verify (student proposes, teacher accepts/rejects) with accepted tokens receiving the full loss and rejected tokens masked. The verification procedure supplies a gate, not a dense teacher distribution on every student-generated token. Downgrade per the SelecTKD rule.
- **ToDi**: abstract never states that the supervised sequences are student-generated. The method is a per-token FKL/RKL blend via log-ratio sigmoid; no C1 evidence in the primary abstract. Downgrade per the ToDi rule.
- **HPD**: explicit mixture — "combines off-policy data with lightweight, approximate on-policy sampling" — so C1 is only partially satisfied. Partial per the HPD rule.

**Caveats:**
- All 2604.x / 2605.x sources are post-knowledge-cutoff preprints; only abstracts (and in some cases HTML v1) were accessible via arXiv.
- Where an exact equation is not in the abstract, C3 quotes are the closest loss-form sentence available; confidence is annotated accordingly.
- No additions to the candidate queue were necessary.
