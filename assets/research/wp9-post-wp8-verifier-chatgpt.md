## Concise Memo

Scope was limited to repository rows already present after the WP6/WP7/WP8 merges. I did not discover new papers and did not evaluate benchmark quality. Evidence below is from primary arXiv PDFs/HTML or official technical reports.

The assigned labels mostly survive if their scope is read strictly. Clean strict rows still have current student rollouts, same-rollout teacher/privileged/expert supervision, and a non-scalar distillation objective. Borderline rows remain below strict because of method-level mixing, hard-label expert continuations, response-level discriminator rewards, quality gates, or diffusion/flow objective ambiguity. Qwen3 OPD is strict only as the disclosed strong-to-weak text stage; Qwen3-VL multimodal RL/SAPO remains adjacent because no visual-language same-rollout teacher distillation loop is disclosed.
