# Research Archive

This directory contains archival research provenance for the landscape. It is not the primary reading path for the repo.

In archived filenames, `WP` means **work package**: an internal audit batch used while building the landscape. Public-facing docs avoid this workflow vocabulary; the archive keeps it so label decisions remain traceable.

## Archive Map

| Area | Contents |
|---|---|
| [syntheses](syntheses/) | Merged audit conclusions and controller decisions. |
| [process](process/) | Historical prompts, planning notes, and handoff/controller files. |
| `wp0/`, `wp1/`, etc. | Raw or semi-raw audit inputs grouped by internal work package. |
| `legacy/` | Earlier landscape drafts kept for provenance only. |

## Work Package Topics

| Work package | Topic |
|---|---|
| WP0 | Survey seed and initial taxonomy audit. |
| WP1 | White-box distributional OPD and redirect cleanup. |
| WP2 | Black-box/API OPD. |
| WP3 | Teacher-free and self-play OPD. |
| WP4 | Reasoning OPD and OPD+RL hybrids. |
| WP5 | Industrial systems, scaling, and framework evidence. |
| WP6 | Agentic and interactive OPD. |
| WP7 | Multimodal, VLM/MLLM/VLA, diffusion, and GUI frontier. |
| WP8 | Evaluation methodology. |
| WP9 | Verifier passes and final boundary cleanup. |
