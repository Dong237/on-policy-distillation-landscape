# Synthesis Archive

Merged audit memos and verifier syntheses live here. These files preserve the reasoning behind current table labels, including conservative downgrades and source-confidence caveats.

Filename prefixes use the historical work-package numbering described in [assets/research/README.md](../README.md). The final landscape is expressed in the root README, table files, taxonomy files, paper-family pages, and implementation notes.

## Current Use

- Read these files when auditing why a label changed.
- Do not treat them as the public navigation surface.
- Prefer current labels from [tables/opd_papers.md](../../../tables/opd_papers.md), [tables/vlm_opd_papers.md](../../../tables/vlm_opd_papers.md), and [tables/adjacent_work.md](../../../tables/adjacent_work.md).
